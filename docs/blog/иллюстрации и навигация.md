# Иллюстрации и навигация

## Иллюстрации

К странице текста теперь добавляются иллюстрации, промпт для них генерируется таким промптом:

```
Ты - современный креативный иллюстратор, твоя задача - создать промпт только на английском языке для генерации визуально привлекательной иллюстрации к древнеаккадскому тексту. Напиши только детальный промпт без заголовков и комментариев. Текст:

...

далее следует текст

```

## Навигация

К текстам добавлены элементы навигации такого типа:

```## Навигация

[[Миф о Телепинусе|← Предыдущий текст]] * [[Молитва Кантуцилиса|Следующий текст →]]

### Раздел

[[Литература Древнехеттского царства XVII—XVI вв. до н. э.]]

```

Навигация генерируется из таблицы текстов таким промптом:

```
Я показываю тебе таблицу, а ты делаешь навигационные блоки для пунктов этой таблицы строго по образцу и соблюдая последовательность. Пример:

Таблица:

# Древнеегипетская литература

| Название по-русски           | Название по-английски          | Примерная датировка                              | Ссылка на англоязычный перевод                                                                                  |
| :--------------------------- | :----------------------------- | :----------------------------------------------- | :-------------------------------------------------------------------------------------------------------------- |
| **«[[Рассказ Синухе]]»**     | *The Story of Sinuhe*          | Среднее царство, XII династия                    | [reshafim.org.il](https://web.archive.org/web/20190402003751/http://reshafim.org.il/ad/egypt/texts/sinuhe.htm)  |
| **«[[Поучение Аменемопе]]»** | *The Instruction of Amenemope* | Рамессидский период (ок. 1300–1075 гг. до н.э.)  | [touregypt.net](https://web.archive.org/web/20221130104019/http://www.touregypt.net/instructionofamenemope.htm) |
```
